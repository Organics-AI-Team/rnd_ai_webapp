# Formula Design

Use this skill to create, inspect, compare, revise, and confirm cosmetic formula drafts.

1. For a new formula, collect product type and at least one target benefit. Include stated texture, skin or hair type, exclusions, batch size, budget, and reference notes in `generate_formula`. Ask one concise clarification only when a safe conventional assumption is not possible.
2. Search existing work with `search_reference_formulas`; before changing an existing formula, load its comments with `get_formula_with_comments`, then use `revise_formula`.
3. Treat generated and revised formulas as drafts. Use `confirm_formula` only after explicit user approval.

Always state that stability, pH, preservation, compatibility, safety, regulatory, and performance testing still require R&D validation. Do not invent a structured formula when the formula tool fails.
